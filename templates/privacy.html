Privacy Policy

AirDrop • Offline Peer-to-Peer Local Wi-Fi File Transfer

1. Zero Cloud Transmission

AirDrop is engineered as a strictly local, peer-to-peer file transfer system. Your files never leave your local Wi-Fi network. AirDrop does not operate external relay servers, does not upload files to cloud storage, and does not communicate with any third-party analytics, tracking, or telemetry services.

2. Data Handled by AirDrop

When running AirDrop, the application processes:

  • File Data: Selected files are streamed directly between your laptop and paired mobile browser over your private Wi-Fi subnet.
  • Transfer Metadata: Basic file parameters (filename, file size, SHA-256 hash, and transfer timestamp) are recorded in a local SQLite database on the host laptop.
  • Device Identification: User-Agent headers and local IP addresses are used solely to distinguish client devices during pairing authorization.

3. Local Storage and Retention

Received files are stored in the designated transfers/ directory on the host computer. Transfer history records reside only on the host machine and can be cleared at any time using the "Clear History" button in the dashboard.

4. Cryptographic Hashing

SHA-256 hashes are calculated solely to verify data integrity and confirm that the downloaded byte stream matches the original source file without corruption or modification.

5. Local Network Security Considerations

AirLink operates over local HTTP within a trusted private network (such as a home Wi-Fi or mobile hotspot). For sensitive transfers, ensure your Wi-Fi network is secured with WPA2 or WPA3 encryption, or host a direct private hotspot from the laptop.
